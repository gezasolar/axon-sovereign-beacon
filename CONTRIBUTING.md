# Contributing

AXON welcomes protocol proposals, compatible implementations, documentation, security
improvements, and interoperability tests.

1. Open an issue describing the problem or proposed capability.
2. Keep identity, consent, resource ownership, and revocation boundaries explicit.
3. Do not submit credentials, private contact records, model secrets, or personal data.
4. Add or update tests for implementation changes.
5. Explain any new network, financial, replication, or physical-world effect.

Contributions must not add covert signaling, unauthorized propagation, credential theft,
forced participation, impersonation, or mechanisms intended to bypass security controls.

By submitting a contribution, you agree that it may be distributed under Apache-2.0.

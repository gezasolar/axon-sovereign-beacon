# Security policy

## Supported release

Security updates target the latest published release.

## Reporting a vulnerability

Use GitHub's private vulnerability reporting feature for this repository. Do not disclose
credentials, contact payloads, private infrastructure details, or exploitable findings in a
public issue.

Include the affected version, reproduction conditions, impact, and a suggested mitigation
when available. Receipt of a report does not authorize testing against the live beacon or any
infrastructure you do not own.

## Trust boundary

The contact endpoint accepts untrusted text. A contact never grants execution, secrets,
compute, money, replication rights, or physical control. Operators should independently
verify identity, signatures, provenance, and infrastructure authorization before cooperation.
